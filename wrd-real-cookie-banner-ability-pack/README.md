# Real Cookie Banner Ability Pack for WordPress MCP

Consent-group inspection and controlled service or content-blocker draft management.

## Compatibility

Pack version: **0.1.0**. Reviewed target: **Real Cookie Banner 5.3.0** (`real-cookie-banner/index.php`). Requires WordPress 7.0+, PHP 8.1+, the named target plugin, and [Agent Connector for WP](https://github.com/soflyy/agent-connector-for-wp). The target version is informative; native capability checks determine which operations are available.

## Install

Follow the [AI-agent installation guide](../INSTALL_FOR_AI_AGENTS.md) to check the target plugin, package this pack as a ZIP, activate it, and verify MCP discovery.

## Use

Read status, groups, and draft details first. Draft changes require a fresh revision, a reason, and a preview.

Available abilities:

- `real-cookie-banner/get-status`
- `real-cookie-banner/get-settings`
- `real-cookie-banner/list-groups`
- `real-cookie-banner/list-items`
- `real-cookie-banner/get-item`
- `real-cookie-banner/get-edit-schema`
- `real-cookie-banner/create-draft`
- `real-cookie-banner/update-draft`
- `real-cookie-banner/trash-draft`
- `real-cookie-banner/restore-draft`
