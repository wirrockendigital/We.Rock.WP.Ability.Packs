# Real Category Management Ability Pack for WordPress MCP

Native category trees, term operations, ordering, post assignments, and selected settings.

## Compatibility

Pack version: **0.1.0**. Reviewed target: **Real Category Management 4.3.7** (`real-category-library/index.php`). Requires WordPress 7.0+, PHP 8.1+, the named target plugin, and [Agent Connector for WP](https://github.com/soflyy/agent-connector-for-wp). The target version is informative; native capability checks determine which operations are available.

## Install

Follow the [AI-agent installation guide](../INSTALL_FOR_AI_AGENTS.md) to check the target plugin, package this pack as a ZIP, activate it, and verify MCP discovery.

## Use

Start with `real-category-management/get-status` and `real-category-management/list-contexts`. Read the tree or assignment revision before a preview or authorized change.

Available abilities:

- `real-category-management/get-status`
- `real-category-management/list-contexts`
- `real-category-management/get-tree`
- `real-category-management/create-term`
- `real-category-management/rename-term`
- `real-category-management/relocate-term`
- `real-category-management/delete-empty-term`
- `real-category-management/get-assignments`
- `real-category-management/assign-posts`
- `real-category-management/get-settings`
- `real-category-management/update-settings`
