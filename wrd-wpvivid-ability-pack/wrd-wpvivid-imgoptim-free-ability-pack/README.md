# WPvivid Imgoptim Free Ability Pack for WordPress MCP

Image-optimization settings and diagnostics for tasks, lazy loading, image status, and image sizes.

## Compatibility

Pack version: **0.1.0**. Reviewed target: **WPvivid Imgoptim Free 0.9.25** (`wpvivid-imgoptim/wpvivid-imgoptim.php`). Requires WordPress 7.0+, PHP 8.1+, the named target plugin, and [Agent Connector for WP](https://github.com/soflyy/agent-connector-for-wp). The target version is informative; native capability checks determine which operations are available.

## Install

Follow the [AI-agent installation guide](../../INSTALL_FOR_AI_AGENTS.md) to check the target plugin, package this pack as a ZIP, activate it, and verify MCP discovery.

## Use

Start with `wpvivid-imgoptim-free/get-status`. Read the current settings revision before previewing or applying a supported setting delta.

Available abilities:

- `wpvivid-imgoptim-free/get-status`
- `wpvivid-imgoptim-free/get-settings`
- `wpvivid-imgoptim-free/get-settings-schema`
- `wpvivid-imgoptim-free/update-settings`
- `wpvivid-imgoptim-free/list-cron-events`
- `wpvivid-imgoptim-free/get-task`
- `wpvivid-imgoptim-free/get-lazyload`
- `wpvivid-imgoptim-free/get-image-status`
- `wpvivid-imgoptim-free/list-image-sizes`
